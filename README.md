# Open-Meteo Weather — плазмоид + плагин календаря KDE Plasma 6 + Android-приложение

Виджет погоды для KDE Plasma 6, плагин погоды для штатного календаря Plasma и Android-приложение на Flutter, использующие **бесплатный** API [Open-Meteo](https://open-meteo.com).

> **Не требует API-ключа.** Просто установите и пользуйтесь.

## 🗂 Структура монорепы

| Каталог | Что это |
|---|---|
| [`package/`](./package) | Плазмоид погоды для KDE Plasma 6 (чистый QML/JS) |
| [`calendar-plugin/`](./calendar-plugin) | C++-плагин «Погода» для штатного календаря Plasma (цифровые часы) |
| [`mobile_app/`](./mobile_app) | Flutter-приложение для Android + home-screen виджет |

Части самодостаточны и не зависят друг от друга; источник данных один — Open-Meteo без ключа.

## 📅 Плагин календаря

В [`calendar-plugin/`](./calendar-plugin) — C++-плагин KF6 `CalendarEvents`: погода прямо в штатном календаре KDE (клик по часам):

- цветные точки под числами (цвет = температура дня)
- подпись «+N°» под числом (subLabel)
- строка погоды в списке «События» + детали (ветер, осадки, УФ, восход/закат)
- прогноз 16 дней вперёд + 7 дней назад, кэш между сессиями
- страница настроек в настройках часов: поиск города, координаты, °C/°F

Сборка и установка: `./calendar-plugin/install.sh` (нужен sudo — плагин ставится в системный каталог `plasmacalendarplugins`). После установки включите «Погода» в настройках цифровых часов (Календарь). Подробности — в [calendar-plugin/README.md](./calendar-plugin/README.md).

## 📱 Android-приложение

В [`mobile_app/`](./mobile_app) — Flutter-приложение «Погода»: собирательный
образ по мотивам популярных погодных приложений (Apple Weather, Яндекс
Погода, Gismeteo, Carrot) с дизайном и характером этого виджета:

- динамический погодный фон + стеклянные карточки (glassmorphism)
- «Осадки сейчас» — nowcast на 2 часа (minutely_15)
- избранные города, поиск, GPS
- график температуры, прогноз до 16 дней, плитки метрик, AQI
- предупреждения о резких изменениях (перепад t°, гроза, ветер)
- тот же сарказм «ощущается как»
- **виджет на рабочий стол Android** (4×2, обновляется и без открытого приложения)
- своя иконка (солнце + облако, генерится из `assets/icon/gen_icon.py`)

Сборка: `cd mobile_app && mise install && mise exec -- flutter build apk --release`.
Подробности — в [mobile_app/README.md](./mobile_app/README.md).

## Возможности

- 🌡 Текущая температура, «ощущается как» (с **язвительной шуткой**), влажность, давление, облачность, точка росы
- 💨 Скорость, **порывы** и направление ветра (русские румбы: С, СВ, ЮЗ…)
- 🌫 **Качество воздуха** — Европейский AQI с цветовой индикацией (Air Quality API)
- 🌅 Восход и закат, ☀️ УФ-индекс, 🌧 осадки за текущий день
- 🌙 Ночная иконка неба (по `is_day`: ясная ночь — 🌙)
- 📅 Прогноз до 16 дней (по дням / по часам / оба режима): макс./мин. температура, **вероятность осадков**
- 📌 Компактный вид для панели: горизонтальная панель — эмодзи + температура, вертикальная — только эмодзи
- 🖥 Развёрнутый вид: карточки текущей погоды, метрик дня (сетка 3×3), качества воздуха и прогноза; строка «Обновлено в HH:MM»
- 📐 **Адаптивная вёрстка**: на рабочем столе виджет перестраивается под размер — 2–3 колонки метрик, компактная шапка на узкой ширине; размер запоминается Plasma
- 🔄 Автообновление (настраиваемый интервал)
- 🇷🇺 Русские названия погодных условий и направлений ветра
- 🌍 Настраиваемые единицы измерения (°C/°F, m/s/kmh/mph/kn)
- 🕐 Поддержка часовых поясов
- 🎨 Вписывается в тему Plasma (Kirigami); ошибки и пустые состояния — стандартный `PlasmaExtras.PlaceholderMessage`

## Установка

```bash
# Для текущего пользователя
./install.sh --user

# Системная установка (требует sudo)
./install.sh --system
```

Скрипт копирует `package/` в `~/.local/share/plasma/plasmoids/com.github.vladimirm.openmeteo-weather`
(при `--system` — в `/usr/share/plasma/plasmoids/com.github.vladimirm.openmeteo-weather`).

Перезапустите plasmashell:

```bash
plasmashell --replace &
```

## Настройка

1. Добавьте виджет: ПКМ по панели → **Add Widgets** → **Environment & Weather** → **Open-Meteo Weather**
2. ПКМ по виджету → **Configure...**:
   - **City name** — название города (для отображения)
   - **Latitude / Longitude** — координаты (Москва: 55.75, 37.62)
   - **Timezone** — часовой пояс (Europe/Moscow, Asia/Yekaterinburg, ...)
   - **Update interval** — интервал обновления (5–180 минут)
   - **Temperature unit** — °C или °F
   - **Wind speed unit** — m/s, km/h, mph, knots
   - **Forecast mode** — по дням / по часам / оба
   - **Forecast days** — до 16 дней

## Как это работает

Чистый **QML + JavaScript** — без Python, C++ или внешних зависимостей:

1. `main.qml` содержит таймер, HTTP-запросы к `api.open-meteo.com/v1/forecast` через `XMLHttpRequest`, парсинг JSON
2. Параллельно запрашивается качество воздуха: `air-quality-api.open-meteo.com/v1/air-quality` (Европейский AQI); при ошибке карточка просто скрывается
3. Запрашиваются `current` (текущая погода), `daily` (метрики дня + прогноз) и `hourly` (почасовой) переменные
4. WMO-коды погоды (0–99) преобразуются в текст и эмодзи; для ясной ночи (`is_day=0`) — 🌙
5. Давление конвертируется из гПа в мм рт. ст.
6. Направление ветра из градусов — в русские обозначения (С, СВ, ЮЗ, ...)
7. Температуры округляются; «ощущается как» сопровождается язвительной шуткой по диапазону
8. UI-компоненты автоматически обновляются через QML data binding

## Источники данных

- **Погода и геокодинг городов:** [Open-Meteo](https://open-meteo.com) (без ключа, CC BY 4.0)
- **Качество воздуха:** [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (Европейский AQI, без ключа)
- **Геолокация по IP:** ipwhois.app (HTTPS; фолбэк — ip-api.com, у бесплатного тарифа нет HTTPS)

## Open-Meteo API

- **Эндпоинт:** `https://api.open-meteo.com/v1/forecast`
- **Бесплатно** для некоммерческого использования
- До **10 000 запросов/день** бесплатно
- Модели: GFS, ECMWF, MeteoFrance, JMA, ...
- [Документация](https://open-meteo.com/en/docs)
