# Погода (openmeteo_weather)

Android-приложение на Flutter — собирательный образ на основе популярных
погодных приложений, с дизайном и характером нашего KDE-виджета из этого
репозитория. Данные — [Open-Meteo](https://open-meteo.com), без ключей.

## Запуск и сборка

Все команды тулчейна идут через `mise` (тулчейн запиннен в `mise.toml`):

```bash
mise install                # один раз: flutter + android-sdk + java 21
mise exec -- flutter doctor

mise exec -- flutter run                       # на подключённом устройстве
mise exec -- flutter build apk --release       # build/app/outputs/flutter-apk/
mise exec -- flutter analyze
mise exec -- flutter test
mise exec -- dart format lib test
```

## Структура

```
lib/
├── main.dart               # точка входа: stores + MaterialApp
├── app_theme.dart          # тёмная/светлая glass-тема, палитра GlassPalette
├── domain/                 # чистая логика без I/O
│   ├── wmo.dart            # WMO→эмодзи/текст, румбы, AQI/UV метки (порт виджета)
│   ├── jokes.dart          # сарказм «ощущается как»: 13 корзин + контекстные пулы
│   ├── nowcast.dart        # разбор minutely_15 → «Осадки сейчас»
│   └── alerts.dart         # предупреждения о резких изменениях (эвристика)
├── data/                   # сеть и состояние
│   ├── open_meteo_api.dart # forecast+minutely_15, air-quality, geocoding
│   ├── weather_state.dart  # единый ChangeNotifier, округления при парсинге
│   ├── settings_store.dart # настройки в shared_preferences
│   ├── cities_store.dart   # избранные города
│   └── location_service.dart # GPS + обратный геокодинг
└── ui/
    ├── home_screen.dart    # лента стеклянных карточек
    ├── cities_screen.dart  # избранное + поиск + GPS
    ├── settings_screen.dart
    ├── background/         # динамический погодный фон с частицами
    └── widgets/            # glass_card, плитки, ленты, график, карточки
```

## Архитектурные правила (по духу AGENT.md виджета)

- `WeatherState` — единственный источник состояния: сеть и парсинг живут в нём,
  UI только читает готовые поля. Округления — при парсинге, не в биндингах.
- Защита от устаревших ответов — счётчик запросов; AQI независим и при ошибке
  просто скрывает карточку.
- Настройки и список городов живут в `ChangeNotifier`'ах; изменения дают
  дебаунс-рефетч 400 мс.
- WMO-маппинг, шутки, румбы и метки перенесены из виджета дословно
  (`../package/contents/ui/main.qml`) и покрыты тестами.

## Производительность

- **Никаких живых `BackdropFilter` в списке.** Десяток блюров на экране —
  главный источник лагов, а при скролле блюр внутри списка ещё и глючит
  (теряет подложку). «Стекло» делается статичным градиентом-бликом
  (`GlassCard`) — вид тот же, цена нулевая. Не добавляйте блюр обратно.
- Частицы фона: предрассчитанный набор (детерминированный seed на условие),
  прогресс квантован до 30 fps, painter в `RepaintBoundary` — перерисовки
  не задевают контент.
- Если захочется вернуть настоящий blur — только через один общий
  `BackdropGroup`/`BackdropFilter` на весь экран, не на каждую карточку.

## Возможности v1

- Hero: крупная тонкая температура, эмодзи, «Ощущается как», саркастическая реплика
- «Осадки сейчас»: nowcast на 2 часа (minutely_15; вне покрытия CE/US карточка скрыта)
- Почасовая лента 48 ч, график температуры, прогноз до 16 дней с градиентными темп-барами
- Плитки метрик (ветер/порывы/роса/влажность/давление/облачность/осадки/УФ/солнце), AQI
- Предупреждения: перепад t° ≥ 8°, гроза, ветер ≥ 15 м/с
- Города: избранное, поиск (geocoding, язык ru), GPS-кнопка
- Настройки: единицы t°/ветра/давления, интервал обновления, тема, анимации, шутки, режим прогноза
- Динамический погодный фон (градиент + частицы), pull-to-refresh, автообновление в форграунде

## Домашний виджет Android

Собирательный образ по виджетам Apple Weather, Pixel Weather и Gismeteo:

- **4×3 (по умолчанию)**: заголовок (эмодзи + температура | город + состояние),
  строка «ощущается + 💧%», **почасовая лента** «Сейчас + 4 часа»
  (время / эмодзи / t°), **строка метрик** (💧 влажность · 💨 ветер ·
  🧭 давление · ☀️ УФ), **прогноз на 3 дня** (Сегодня / Завтра / день
  недели, эмодзи, max/min), время обновления.
- **4×2 (сжатый)**: при уменьшении виджета часы и метрики скрываются —
  компактный вид. Переключение — по `onAppWidgetOptionsChanged`
  (`setViewVisibility`, без второго layout'а).
- Тап открывает приложение.

Механика:

- Данные пишет Dart-сторона после каждого успешного обновления
  (`lib/data/widget_sync.dart` → плагин `home_widget` → prefs
  `HomeWidgetPreferences`); ключи без данных записываются пустыми.
- Нативная сторона: `WeatherWidgetProvider.kt` + `res/layout/weather_widget.xml`
  + `res/xml/weather_widget_info.xml` — при `onUpdate` просто перерисовывает
  сохранённые значения.
- Фоновое обновление без открытого приложения — периодическая задача
  `workmanager` (мин. 15 минут; интервал берётся из настроек) — тот же
  `WeatherState`, отдельного парсинга нет.
- Чтобы виджет ожил: добавьте его на рабочий стол и один раз откройте
  приложение (первая порция данных приходит из приложения).
- Разметка — только view из белого списка RemoteViews
  (Frame/LinearLayout, TextView; **Space нельзя** — лаунчер падает
  с «не удалось загрузить виджет»).

## Иконка

Рисуется скриптом `assets/icon/gen_icon.py` (PIL): солнце + облако на
градиенте неба. После правки скрипта: `python3 gen_icon.py`, затем
`mise exec -- dart run flutter_launcher_icons` (конфиг — в pubspec.yaml).

Не вошло в v1: радар-карта осадков, английская локализация.
